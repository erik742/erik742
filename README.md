# 🧩 «Вместе» — друзья рядом

Мобильное веб-приложение, которое помогает **подросткам с особыми потребностями находить друзей**, а их **родителям — быть рядом и вовремя помочь**.

## Возможности

### 👋 Для подростка
- **Регистрация по номеру телефона или электронной почте** с подтверждением кодом (в демо-режиме код показывается на экране).
- **Поиск друзей по интересам** — простые карточки с эмодзи, общие интересы подсвечиваются.
- **Аудио- и видеозвонки** друзьям (WebRTC): переключение камеры, выключение микрофона.
- **Простой чат** с готовыми фразами («Привет! Давай дружить») — не нужно придумывать текст.
- **Кнопка SOS** — нажмите и держите 2,5 секунды: родители мгновенно получят сигнал с координатами.
- **Советы «Как действовать при опасности»** — крупный текст + озвучка голосом (синтез речи).
- **Доступность**: крупные кнопки, эмодзи-иконки вместо абстрактных значений, озвучка важных событий.

### 👨‍👩‍👧 Для родителя (родительский контроль)
- **Мгновенное местоположение** ребёнка на карте (OpenStreetMap): координаты, точность, время обновления, кнопка «Где сейчас».
- **Просмотр через камеру по запросу** — передняя или задняя камера: родитель отправляет запрос, ребёнок подтверждает, родитель видит и слышит, что происходит, может переключать камеру.
- **Прослушивание по запросу** — только звук, без видео.
- **Советы при опасности** — библиотека сценариев («незнакомец зовёт встретиться», «просят фото», «обижают в чате»…) и быстрые подсказки, которые крупным текстом появляются на экране ребёнка и озвучиваются вслух.
- **SOS-уведомления** — тревожный сигнал и карта, история сигналов.
- **Друзья и переписка ребёнка** — родитель видит, с кем общается ребёнок.

### 🛡 Этика наблюдения
Наблюдение построено на **согласии**: родитель отправляет *запрос*, ребёнок видит уведомление и решает — показать камеру/микрофон или нет. Во время трансляции у подростка горит заметный баннер «Родитель смотрит» с кнопкой «Стоп». Это важно для доверия и комфортa подростков с особыми потребностями.

## Как запустить

```bash
npm install
npm run build        # сборка фронтенда
npm start            # сервер на http://localhost:3000
```

Для разработки: `npm run dev` (Vite на :5173, API нужно поднять отдельно `npm start`).

## Демо-данные

При первом запуске создаются 8 демо-подростков с разными интересами:
- телефон `+79000000001` … `+79000000008`, пароль `demo1234`.
- Они **сами принимают заявки в друзья** и отвечают в чате — удобно проверять приложение в одиночку.

## Как проверить сценарий «родитель + ребёнок»

1. Откройте приложение в двух окнах браузера (можно в двух вкладках).
2. В окне 1 зарегистрируйте **подростка** (телефон или почта) и выберите интересы в разделе «Я».
3. В окне 1: «Я» → «Подключить родителя» — появится код.
4. В окне 2 зарегистрируйте **родителя** и введите код.
5. Родитель: местоположение, запрос камеры/микрофона, советы, SOS.
6. Подростку в разделе «Найти» отправьте заявку демо-ребятам — через несколько секунд они примут её, и можно общяться и звонить.

> Камера, микрофон и геолокация требуют HTTPS и разрешений браузера.

## Технологии

- **Фронтенд**: React 19 + TypeScript + Vite, без UI-библиотек (крупные элементы и простые формы — важная часть дизайна).
- **Бэкенд**: Node.js + Express + Socket.IO (`server/`), данные в JSON-файле `server/data.json`.
- **Связь в реальном времени**: WebRTC (аудио/видео звонки, трансляция камеры и микрофона родителю), Socket.IO — сигналинг, чат, местоположение, SOS.
- **Синтез речи** — Web Speech API (ru-RU) для озвучки советов и звонков.

## Структура

```
server/index.mjs      — API + WebSocket-сигналинг
server/store.mjs      — простое JSON-хранилище
server/advice.mjs     — библиотека советов при опасности
src/screens/          — экраны (вход, подросток, родитель)
src/lib/              — api, сокет, синтез речи, константы
```
